# 生图与真实尺寸切图

本规则适用于从效果图拆分素材、把生图拆成多个 SpriteFrame、制作按钮/面板状态图，或把一张合图拆成可复用 UI 资源。目标是让“来源像素、切片像素和设计分辨率下的 UI 尺寸”三者可追溯，不用运行时缩放去补偿错误切图。

## 1. 制作前确定正式尺寸（强制前置条件）

在执行任何生图、裁切、重采样或合图操作之前，先依据效果图到工程设计坐标的映射和项目设计分辨率确定每个素材的正式尺寸，并写入蓝图或素材规格表。拼装画布直接使用工程设计分辨率，不依据设备适配轴扩展。尺寸未确定时不得开始制作；不能把这一步推迟到导入前检查，更不能先生成素材再按生成结果临时决定尺寸。

每个素材至少记录：

- 效果图测量区域、完整容纳原图的统一等比缩放系数、居中留白偏移和正式尺寸的计算依据；
- 来源图的实际像素宽高和方向；尚未生图时记录计划制作画布尺寸，并在生成后补充实际尺寸；
- 已有来源图中的切片矩形 `x, y, width, height`；生图素材先记录计划区域和布局约束，生成后根据实际来源尺寸核对切片矩形；
- 正式输出 PNG 的目标像素宽高、透明留白、预期可见边界和是否允许 trim/旋转；
- 工程实际设计分辨率下的目标 `UITransform` 宽高、锚点和 `Sprite.sizeMode`；
- 需要旋转或拼接的素材，记录旋转中心、各接口中心坐标和口径，全部使用正式输出画布坐标；
- 若用于九宫格，记录源 SpriteFrame 的 border，而不是把面板直接拉伸成目标尺寸。

正式 PNG 文件尺寸与节点显示尺寸是两项独立检查。普通固定尺寸素材默认按设计像素 1:1 输出；例如规格规定完整画布为 `126 × 126`，正式 PNG 就必须是 `126 × 126`，不能导入 `1254 × 1254` 图片后仅将节点设为 `126 × 126`。九宫格等可拉伸素材按制作前确定的源切片尺寸输出，不能把拉伸后的节点尺寸误当作源切片尺寸。

切片矩形以真实可见包围框和设计测量结果为依据。来源图与效果图尺寸不同，先记录来源图与效果图之间的像素映射，再结合效果图到设计坐标的映射确定切片区域和正式输出尺寸；坐标统一在最后一步取整，不能多次缩放、四舍五入后再凭目测修边。

## 2. 生图与切片

- 按已确定的正式尺寸制作。生成工具需要更大的画布时，必须在生图前记录制作画布、正式输出尺寸及裁切/重采样方案；大图只作为制作源，按既定方案输出正式 PNG 后才能导入工程。工具返回尺寸与请求不同也不得改变正式尺寸，不得直接导入大图并靠 `UITransform` 或 `scale` 缩小显示。
- 一个生成画布包含多个素材时，素材之间必须留出可测量的间隔，并在清单中记录每个素材的矩形；透明背景优先，禁止把整张效果图或带 UI 文字的截图直接当作 Sprite。
- 采用外部或脚本切图时保留原始 RGBA，不要自动 trim、旋转或改色，除非这些设置已写入尺寸契约。裁切完成后重新测量透明边界，确认输出文件尺寸与清单一致。
- 面板、按钮和气泡等可拉伸素材要区分“源切片真实尺寸”和“目标 UITransform 尺寸”；源图不能为了匹配目标面板而事先拉伸，使用 SLICED 或工程约定的适配方式处理。

## 3. 导入与绑定前检查

导入前读取实际输出 PNG 的像素宽高、透明通道和可见边界，与制作前的规格逐项核对；旋转或拼接素材同时检查接口位置与口径。尺寸不一致时重新按既定规格输出，不能修改规格去迁就错误产物，也不能以节点显示正确代替文件尺寸检查。

使用 AssetDB 导入后等待 idle，并重新查询 Texture/SpriteFrame 的真实宽高、UUID、trim/旋转信息。任何一项与尺寸契约不一致，都要回到生成或切图步骤修正，不能通过任意 `scale`、父节点补偿或改变点击区域掩盖。

SpriteFrame 绑定后再次设置并核对 `UITransform.contentSize`、锚点、透明度、覆盖文字相对偏移和交互热区，因为 Creator 可能在绑定 RAW 资源时自动写入节点尺寸。固定尺寸图标通常使用 `SIMPLE`/`CUSTOM`；面板类资源按契约使用 `SLICED` 并复核 border。

## 4. 验收门槛

验收顺序固定为：制作前确定尺寸并记录规格 → 按规格制作和输出 → 核对 PNG 实际尺寸 → 导入 Creator → 复查 SpriteFrame 与节点 → 检查显示、旋转/拼接和交互。

真实渲染前至少核对制作前规定的正式尺寸、实际 PNG 文件尺寸、来源切片矩形、导入 SpriteFrame 的原始画布与 trim 信息，以及设计分辨率下的 UITransform 尺寸。正式 PNG 必须符合制作前的规格；其余映射必须能由已记录的裁切和缩放方案解释。仅有 UITransform 尺寸正确或结构校验通过不能视为尺寸验收通过。预览中出现被裁切、拉伸、透明留白异常、文字与底板错位或点击热区偏移时，先修复切片契约，再继续拼装和像素比较。
