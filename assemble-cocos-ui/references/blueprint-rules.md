# UI Prefab 蓝图规则

## 先判断 Prefab 职责

不同职责不能套用同一根结构：

| 类型 | 根结构重点 | 常见内容 |
| --- | --- | --- |
| 全屏窗口 | 设计分辨率、根控制器、内容容器、适配 | 背景、顶部栏、主体、底部操作区 |
| 弹窗 | 外部点击区、面板、输入拦截、打开关闭动画 | 遮罩、主面板、关闭按钮 |
| HUD | 分散锚定、安全区、长期动态刷新 | 顶栏、快捷入口、红点、状态条 |
| 可复用控件 | 自身尺寸、公开状态、最小控制边界 | 货币栏、奖励项、广告按钮 |
| 列表项 | 模板尺寸、Layout 间距、数据绑定 | 图标、数量、按钮、状态层 |
| 特效或状态节点 | 播放边界、Sorting、默认激活状态 | Spine、Animation、粒子、提示层 |

先选择同目录且职责相同的参考 Prefab。全屏窗口统计不能强制套到列表项，复杂 HUD 也不能作为普通弹窗模板。

## 输入拆解

| 类别 | 需要识别的内容 |
| --- | --- |
| 界面 | 全屏页、弹窗、HUD、控件、列表项、状态节点 |
| 基准 | 效果图分辨率、工程设计分辨率、根节点尺寸 |
| 区域 | 背景、顶部栏、标题、内容、列表、按钮、提示、关闭区 |
| 控制 | 根业务组件、嵌套控制组件、引用收集器作用域 |
| 来源 | 本地节点、嵌套 Prefab、固定槽位、模板、运行时生成 |
| 变化 | 显隐、换图、变色、文字、缩放、动画 |
| 数据 | 动态文本、动态图片、列表项、进度、倒计时 |
| 交互 | MButton 或 Button、Switch、Toggle、滚动、分页、关闭遮罩 |
| 状态 | Loading、Content、Empty、Locked、Selected、Disabled 等 |
| 适配 | 固定边、居中、安全区、可伸缩区域、背景填充方式 |

无法确定且会改变节点结构的内容标记“待确认”。只影响微调的数值可以估算，但必须写出依据。

## 控制器与引用作用域

- 将控制组件所在节点视为作用域根。记录该组件管理的引用、按钮和动态模板。
- `ReferenceCollector` 类组件只收集自身有效子树。遇到嵌套收集器时，外层作用域在该子树处停止。
- `$Name` 等项目约定的引用节点名属于脚本接口。蓝图同时记录节点完整路径、收集器路径和脚本使用的 key。
- 同一作用域中规范化后的 key 必须唯一。移动节点跨越收集器边界时，视为接口变化。
- `MUIComponent` 一类控制器自动扫描按钮时，记录最近控制器归属。不要同时规划自动分发和指向同一逻辑的 Inspector 回调。
- 只有目标脚本或相邻 Prefab 已经使用序列化事件时，才规划 `EventHandler`。
- 重构已有 Prefab 时，节点路径还可能被 AnimationClip、`getChildByPath` 或实例属性覆盖引用。重命名或换父节点前必须查询这些绑定。

## 节点来源与复用

每个关键节点必须归入一种来源：

- `local`：当前 Prefab 直接序列化的节点。
- `instance`：已有 Prefab 实例。记录 `db://` URL、实例根路径和必要的属性覆盖。
- `template`：Prefab 内保留的同构运行时模板。记录默认激活状态和克隆位置。
- `runtime`：脚本运行时创建，蓝图只定义父容器和生成契约。

公共 Prefab 能满足职责时使用 `instance`，不要复制其内部树。需要差异时优先使用实例属性覆盖或新增外层容器；只有公共结构本身需要统一变化时才修改源 Prefab。

## 推荐渲染层

按同级节点从前到后排列：

1. 全屏或面板背景
2. 静态装饰
3. 主要内容
4. 操作控件
5. 状态提示、红点、浮层
6. 粒子、特效、引导

弹窗可采用以下结构，但必须以相邻 Prefab 为证据：

```text
DialogRoot
├── CloseOverlay
├── home
└── GuideLayer
```

说明 CloseOverlay 的层级、点击范围、是否关闭弹窗和是否需要 `BlockInputEvents`。不要在所有界面上自动添加遮罩或关闭热区。

## 节点拆分

满足任一条件时拆成独立节点：

- 需要独立显隐、换图、换色、改文字、缩放或播放动画。
- 需要独立点击区域。
- 是动态数据槽位、固定设计槽位或重复项模板。
- 承担 Layout、Widget、Mask、滚动、控制器边界、状态互斥或动画分组职责。
- 在渲染顺序上必须插入其他内容。

以下情况保持整体：

- 一张不会变化的完整装饰图。
- 拆分后没有布局、交互、状态、控制或复用价值。
- 仅为视觉对齐产生的空父节点。
- 已有公共 Prefab 的内部结构；在当前蓝图中将其作为实例处理。

页面根或面板根只保留全局背景、独立浮层以及主要功能区域。账号信息、设置项、操作区、页脚等包含多个同职责节点的内容应各自进入语义明确的容器，避免叶子节点完全平铺。分组前先检查脚本路径、AnimationClip 和 Prefab 覆盖；这些契约存在时同步迁移引用或保留原路径。

视觉上附着于底板、标题牌、按钮背景、图标底框的文字、图标或徽标，应作为该承载节点的后代，或与承载素材进入同一零偏移容器。蓝图除画布绝对坐标外，还要记录覆盖元素相对承载素材的局部坐标或中心偏移；不要让视觉绑定元素分属互不相关的父节点后分别定位。

## 组件选择

先遵循目标工程的自定义组件，再使用对应的 Cocos 内置组件。

| 需求 | 首选组件 | 关键约束 |
| --- | --- | --- |
| 所有本地 UI 节点 | UITransform | 明确尺寸、锚点、本地位置 |
| 图片 | Sprite | 明确 Type、SizeMode、比例、资源和动态换图 |
| 普通文字 | Label | 明确字号、行高、颜色、对齐、Overflow |
| 富文本 | RichText | 仅在确有混排、链接或富文本标记时使用 |
| 点击 | 项目按钮组件或 Button | 根节点作为热区，视觉内容放子节点 |
| 显示状态切换 | 项目 Switch 或独立状态组 | 明确直接子节点顺序、名称和默认状态 |
| 用户互斥选择 | Toggle + ToggleContainer | 明确默认选中和是否允许取消 |
| 自动排列 | Layout | 先设子节点尺寸，再更新 Layout |
| 裁剪 | Mask | 必须是被裁剪内容的祖先 |
| 滚动 | ScrollView | 明确 viewport、Content、方向、惯性与回弹 |
| 进度 | ProgressBar | 明确 barSprite、方向、总长；简单填充可用 FILLED Sprite |
| 翻页 | PageView | 只有逐页切换语义时使用 |
| 全屏或边缘适配 | Widget | 避免与同轴 Layout 或手动尺寸冲突 |
| 输入拦截 | BlockInputEvents | 弹窗或浮层按需要添加 |
| 动画 | Animation | 只有节点需独立控制的动画才添加 |

项目 `Switch` 如果只是按索引或名称控制子节点显隐，不得改写为 Toggle。Toggle 表示用户选择行为，两者语义不同。

## Sprite 与 Label

Sprite 规则：

- `SIMPLE` 用于固定尺寸图标或等比缩放图片。
- `SLICED` 用于有正确九宫格边界的面板、按钮背景和气泡。
- `TILED` 仅在纹理可重复且效果图明确要求平铺时使用。
- `FILLED` 用于进度、冷却或遮罩填充；说明方向和范围。
- 人物、图标、文字纹理和复杂装饰保持比例。
- 已提供或可唯一定位的资源写出 `db://` 来源；缺少对应资源时才使用纯色 Sprite 占位，并标记为近似效果。

Label 至少说明文字或占位、UITransform 尺寸与锚点、FontSize、LineHeight、颜色、水平对齐、垂直对齐、Overflow、描边、阴影、自动缩小、多行和动态更新。描边使用 Label 自身的 `enableOutline`、`outlineColor`、`outlineWidth`，不规划或添加独立 `LabelOutline` 组件。对齐方式必须符合语义：居中标题和按钮文字以目标视觉区域中心定位，左对齐正文以文本起始边定位；不得用错误的对齐方式加节点偏移来凑字形位置。无法识别文案时使用语义占位，不虚构业务文本。

## 复合控件

### 按钮

```text
ConfirmButton [UITransform, ProjectButton]
├── ButtonBackground [UITransform, Sprite]
├── ButtonIcon [UITransform, Sprite]
└── ButtonLabel [UITransform, Label]
```

按钮文字必须位于对应 Button 节点的子树中，通常使用直接子节点 `ButtonLabel`；不得把按钮文字作为 Button 的同级节点。说明热区、Transition、normal/pressed/disabled 视觉、事件归属和按钮稳定名称。需要扩热区时扩大按钮根节点，不拉伸视觉子节点。

### ScrollView

```text
RewardScrollView [UITransform, ScrollView]
└── view [UITransform, Mask]
    └── Content [UITransform, Layout]
        └── ItemTemplate [UITransform, template]
```

蓝图必须写明 viewport 和 Content 的路径。若目标工程允许 `ScrollView.view` 留空并通过带 Mask 的 `content.parent` 推断 viewport，记录“viewportSource = content.parent”；不要为了满足通用示例增加多余层级。明确 Content 的 Layout 方向、间距、边距、锚点、初始位置和模板激活状态。

### Switch 与 Toggle

- 项目 Switch：列出直接子节点的稳定顺序、默认 `checkIndex`，以及脚本是否按名称更新。
- Toggle：列出 ToggleContainer、默认项、`allowSwitchOff` 和 checkMark。
- 状态差异只涉及属性时复用节点；大范围结构差异才创建状态组。

## 重复内容

规划前将重复内容分类：

| 类型 | Prefab 中的处理 |
| --- | --- |
| 固定槽位 | 保留全部槽位，给出稳定路径或索引 |
| 状态子节点 | 保留全部直接子节点，顺序是状态契约的一部分 |
| 动态同构列表 | 保留一个模板或使用嵌套 item Prefab，说明运行时数量 |
| 设计预览样本 | 说明哪些样本保留、运行时是否清空 |
| 脚本完全生成 | 只保留 Content 和生成挂点 |

不要仅凭多个相似节点就删除副本。先搜索脚本是否按 `children[index]`、固定名称、固定数量或 Switch 索引访问它们。

## 状态与默认激活

- 页面级状态放在稳定的状态区域下并明确互斥关系。
- Loading、Empty、Content 只有在需求、效果图或相邻实现支持时添加。
- Claimable、Claimed 等业务状态不得仅凭常见模式虚构。
- 默认禁用可能表示状态备选、模板、特效或引导。蓝图必须保留初始 `_active` 语义，并说明由谁激活。
- 红点、倒计时、价格、数量、头像和远程图片标为动态内容。

## 动画与排序边界

- AnimationClip 绑定到节点路径时，路径属于资源接口。蓝图记录需要保留或同步迁移的轨道目标。
- Animation、Tween 或业务脚本会修改位置、缩放、透明度或激活状态时，不再给同一属性增加冲突的持续布局控制。
- Sorting2D 和项目排序组件可能定义整棵子树的排序或遍历停止点。规划重排时保留作用域边界，不随意把内部 Sprite 移出边界。
- 嵌套 Prefab 的属性覆盖可能通过本地 fileId 指向实例内部对象。保持实例关系，并通过编辑器 Prefab API 管理覆盖。

## 分辨率适配

- 使用效果图尺寸作为视觉测量基准，同时记录工程设计分辨率。
- 全屏背景四边对齐，并说明超宽或超长屏的裁剪策略。
- 顶部区域优先 Top，底部操作区优先 Bottom，弹窗主体水平和垂直居中。
- 可伸缩内容区使用左右或四边约束；图标、按钮和字体通常保持固定尺寸。
- 刘海屏相关内容放入安全区容器或明确安全边距。
- 同一轴只确定一个主要控制者：Layout 控制排列，Widget 控制相对父节点的边距或居中，手动坐标控制固定位置。
